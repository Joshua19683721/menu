🤖 安裝「AI 解題」書籤

在任何題目網頁按一下書籤，右側就會出現解題面板，直接讀那一頁的文章與題目。

① 把按鈕拖到書籤列

🤖 AI 解題 用滑鼠按住，拖到瀏覽器書籤列

書籤列沒開：按 Ctrl+Shift+B。Mac 是 ⌘+Shift+B。

不能拖的話：按下面的「複製書籤程式碼」→ 書籤列按右鍵 →「新增書籤」→ 名稱填 AI 解題 → 網址貼上。

② 第一次使用要貼 API Key

  1. 到任何題目網頁，按一下書籤列的「AI 解題」。
  2. 右側面板右上角 ⚙ → 貼上 DeepSeek API Key（sk-…）→ 儲存。
  3. 按「測試連線」看到 ✔ 就連線成功。

金鑰只寫進這台電腦、這個網站的 localStorage，不會上傳到任何伺服器。 換一台電腦、或換一個網站使用時，要再貼一次（每台電腦各自保存）。

③ 不用書籤也可以

直接開 助手頁面，把題目或文章貼進去就能用，同樣是金鑰存在本機。
