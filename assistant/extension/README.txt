====================================================
  AI 解題助手 — 瀏覽器擴充功能（Chrome / Edge）
====================================================

【這個版本解決什麼】
- 左邊換頁（整頁重新載入）之後，右側面板會「自動再出現」，不用一直點書籤
- Alt+Q 隨時顯示／隱藏；Alt+R 重新讀取左側內容
- DeepSeek API Key 只要輸入一次，存在這台電腦的擴充功能裡，所有網站共用
  （網站本身的 JavaScript 讀不到這把金鑰）

----------------------------------------------------
【安裝】約 30 秒
----------------------------------------------------
1. 把這個資料夾解壓縮，記住路徑（資料夾裡要有 manifest.json）。
2. 開啟 Chrome（或 Edge），網址列輸入：
     Chrome：chrome://extensions
     Edge  ：edge://extensions
3. 打開右上角的「開發人員模式 / Developer mode」。
4. 按「載入未封裝項目 / Load unpacked」，選剛剛解壓縮的資料夾。
5. 清單出現「AI 解題助手 — 右側面板」就完成了。
   建議按一下右上角的拼圖圖示，把本擴充功能「釘選」到工具列。

（Chrome 每次啟動可能提示「停用開發人員模式擴充功能」，按「保留」即可，
  不影響使用。這是所有非商店擴充功能的正常提示。）

----------------------------------------------------
【使用】
----------------------------------------------------
- 開任何網頁 → 右側自動出現面板（第一次會請你貼 API Key）。
- Alt+Q：顯示／隱藏面板
- Alt+R：重新讀左側這一頁
- 點工具列上的擴充功能圖示：也是顯示／隱藏
- 面板右上角 ⚙：貼 API Key、改模型、測連線
- 面板右上角 ⟳：重新抓取左側內容

換頁、重新整理、開新文章 → 面板會自己回來，不用再點書籤。

----------------------------------------------------
【常見問題】
----------------------------------------------------
Q：為什麼每個網站都會出現面板？
A：這是刻意的（工具列常駐）。不想看就按 Alt+Q，狀態會記住，
   之後每個網站打開都是收起的，要用的時候再按 Alt+Q。

Q：面板抓到錯的內容（例如抓到選單）
A：按「框選範圍」，點一下文章區塊，之後這個網站都會記住那個區塊。

Q：金鑰存在哪裡？
A：chrome.storage.local（這台電腦、這個瀏覽器設定檔）。
   不會上傳到 GitHub、也不會存到網站自己的 localStorage。

Q：要怎麼更新？
A：把新的 panel.js 覆蓋掉舊的，回到 chrome://extensions 按一下「重新載入」。
