📖ReadExpress-CoT 閱讀快線

國小素養版 · 靜態網頁版 · 純前端運算

一篇文章配十階漸進提問，從「讀到什麼」一路帶到「你怎麼想」。 答題可以打字、也可以直接開口講，答錯不會被丟到下一題，而是停下來給一張逐題解析卡。

  • 8 大文章類別：記敘抒情／說明科普／古典成語／現代詩／小說戲劇／臺灣文化／人物社會環境／寓言童話
  • 10 階提問階梯：細節理解 → 推論分析 → 省思評鑑，三層遞進
  • 雙輸入容錯判定：打字或語音辨識；數字優先解析、模糊比對有信賴門檻，判定不出來就交還給學生確認，寧可重問也不猜錯
  • 答錯必給解析：說明「為什麼是這個答案」，可選擇再試一次或直接看正解
  • 閱讀思考拼圖：把十題答案組成一段反思，並展開 3 步驟 CoT 思維鏈
  • 選項順序洗牌：固定種子讓正解平均落在四個位置，不會永遠選 A；重整頁面位置也不跳動
  • 語音全在本機：瀏覽器端完成朗讀與辨識，學生的聲音不會上傳到任何伺服器；Firefox 自動停用語音並提示改用打字

中文｜寫作思辨 國小四年級 Key 只存本機

🎒國文會考魔法寫作小幫手

先說後寫 · 三步驟思辨練習 · 單檔 App

孩子先開口把事情講出來（或直接打字），AI 導師再丟兩個引導問題把他往深處問， 最後產出一篇符合國中會考架構的 400～600 字作文，外加一張 Keep／Change 診斷卡。

  • 三步驟流程：口述／輸入 → 蘇格拉底式提問 → 成稿與診斷卡，每一步都能回上一頁修改
  • 4 個內建主題：印象深刻的比賽、和朋友的誤會、最難忘的雨天、自訂主題
  • 兩題引導分別對應：五感與心理細節、轉折與因果關係；不滿意可以請導師換題
  • 作文診斷卡：做得很好的地方（Keep）、可以更好的地方（Change）、整理好的會考架構文章，並標示字數是否落在 400～600
  • 錯別字雙層檢核：內建字典 81 組零延遲先修（成語誤寫、同音字、台灣用語），再由國文老師 LLM 背景校對的／地／得、標點、語序、重複字詞
  • 繁體中文保證：程式層內建 1157 組逐字對照 + 60 組台灣慣用詞（软件→軟體、網絡→網路、視頻→影片），孩子用簡體字口述也不會冒出簡體
  • 隱私：Groq API Key 只存在本機瀏覽器 localStorage，沒有後端，作文內容不上傳；可複製、列印或存成 PDF

⌨️場景式英文輸入練習 · A2 Key

60 個生活場景 · 逐字敲出單字、片語與句子

把「看得懂」變成「打得出來」。60 個生活場景裡，每一張卡都是一個可以真的用打字機打進去的英文單位， 打錯會震動退回、錯三次自動提示並朗讀。

  • 5,685 個可練習單元：單字 3,163 筆、片語 840 筆、例句 840 筆，60 個場景分六組（生活主題／文法基礎／動詞／形容詞／名詞／會話表達）
  • 官方詞表 100% 涵蓋：Cambridge A2 Key Vocabulary List 1713 / 1713 詞全數收錄
  • 四種練習模式：單字（比字母）、片語（比詞）、句子（逐詞、標點跳過）、盲打整句（不給提示，最接近考試）
  • 盲打分色標記：以最長公共子序列對齊，綠色正確／紅色打錯／紅色漏打／黃色多打，正確率＝正確字數 ÷ 目標字數
  • 即時 IPA 音標：單字片語音標為人工撰寫，840 個例句的音標在執行時逐詞組合出來，並處理連續發音修正；任何一個字查不到就整句不顯示
  • 解析面板：句中每個詞的詞性與中文對照，詞性由官方標註建表 + 上下文判斷（glass 是名詞還是形容詞要看位置）
  • 錯題本與統計：依累計錯誤次數排序的跨場景錯題本；完成單元數、總字元、平均正確率、練習天數；今日挑戰 20 張、隨機挑戰（沒練過的單元權重 ×3）
  • 輸入法友善：全形、智慧引號、中文輸入法產生的雜訊一律靜默丟棄，組字中完全不碰輸入框

🍎場景單字輸入練習 · 英語單字口袋書

21 個生活場景 · 889 條單字 · 1–6 級

從國小到國中的單字，一條一條循序漸進：單字 → 詞組 → 整句， 每一個步驟的內容都出自同一條條目，不會東拼一句西湊一句。

  • 889 條單字 / 3,153 個練習步驟，21 個生活場景分類，可依 1–6 級篩選
  • 三段式練習：目標單字 → 同句例句裡的另一個字 → 固定詞組 → 完整例句
  • 音標 100% 覆蓋：889 個單字與全部練習步驟都有 IPA，由 CMUdict 離線換算並把重音標記修到音節開頭
  • 查單字：889 個單字全部可查，英文、中文、音標、例句都能搜尋，命中處反白；點任一列直接跳到該單字所屬場景開始練習
  • 錯字本顯示真正打錯的字：不是它所在單元的目標字，而是實際失手那個字自己的中文與音標；點回去會清掉舊答案讓你重打一次
  • 學習統計：各場景完成度條；進度自動存在瀏覽器，重開接續
  • 逐條校對：889 條全部逐條檢查過，並修正原書本身的錯誤（如 everyday → every day、chess＝西洋棋）
  • 繁體稽核：建置流程會掃描整個專案，只要出現一個簡體字就失敗；台灣用語（台灣、吃飯、游泳）不受影響

🧭建議學習路徑

五套系統可以單獨使用，也可以照著順序組成一個循環。

  1. 1

    英文輸入打底

    先用 口袋書單字練習 把 1～6 級常用字敲熟，再進 A2 Key 場景練習 把片語與整句補上。

    重點是「打得出來」。看得懂但打不出來的字，寫作時會直接變成空白。

  2. 2

    課本式加深

    接著用 60 課互動課本 把文法放進故事裡：先讀懂整段文章，再回頭看句中解析。

    遇到錯題或想查某個考點，兩張涵蓋範圍對照表可以直接點回對應課次。

  3. 3

    中文閱讀理解

    六年級以後進入 ReadExpress-CoT 閱讀快線，每篇文章十階提問，最後收斂成一段閱讀思考拼圖。

    答錯不要急著看下一題——先讀完那張解析卡，這一關的價值都在裡面。

  4. 4

    中文寫作思辨

    最後用 國文會考魔法寫作小幫手 把想法說出來，讓導師追問兩輪，再看診斷卡與成稿。

    寫作卡住時，多半不是詞彙不夠，而是還沒想清楚——這套系統先處理「想清楚」。
